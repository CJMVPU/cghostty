# 字体所有权、窗口时序及测试产物维护（2026-09-23）

版本：0.2.4（build 14）；平台：macOS 27 / Apple Silicon arm64，Zig 0.16.0。

## 改动范围

- CoreText 的三条字体名称读取路径统一把名称复制到调用者缓冲区，并释放系统返回的字符串。返回值不再借用系统字符串内部存储。
- 删除空的字体 Library、无效初始化／释放及调用参数，合并延迟字体加载的单层转发，移除 8 处无调用者的 GTK 类型占位。
- 隐藏动画完成前检查当前切换编号和可见意图，防止旧回调隐藏已经重新显示的快速终端。
- 焦点请求由窗口控制器统一管理，依赖真实视图挂载事件，不再进行固定时间重试。新请求、实际终端焦点变化、视图移除、窗口关闭会使旧请求失效；新的文本编辑优先，包括不同文本框共用同一个 AppKit 编辑器的情况。命令面板关闭使用当前目标并核对请求及响应者状态。
- 使用 Zig 语法树定位并迁移 PageList 的 Builder、PageAllocation 和独立页面分配函数到仅测试编译可用的 TestSupport。保留原有搜索、混合宽度页面、页面标识、内存限制和分配失败测试；没有删除解析、页面存储或压缩逻辑。
- 默认原生测试结果进入固定构建目录下的 ManagedTestResults。项目锁覆盖运行、摘要提取及清理；最多保留最近 1 个成功、2 个失败结果包，总量上限 512 MiB，保留最近 20 份 JSON 摘要。显式结果路径、自定义构建目录、其他名称和符号链接目标不参与清理。旧 DerivedData/Logs/Test 结果不自动迁移。

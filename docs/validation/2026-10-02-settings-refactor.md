# 设置系统重构验证

日期：2026-10-02。六项重构逐项提交；最终版本元数据为 0.4.7 / build 37。
功能验证使用更新后源码的 Debug 构建（版本提升前为 0.4.6 / build 36）。
本记录不代表已生成 0.4.7 安装包或发布版本。

## 实现范围

1. 诊断使用独立字段键、类型和消息；按完整字段名定位，不改写路径或用户输入。旧核心的文本诊断只识别准确的键名前缀。目录解码失败明确报错。
2. 一次完整校验返回解析结果与诊断；连续输入合并校验，保存重新完整校验，关闭窗口刷新待校验草稿。按值与错误变化刷新可见控件。
3. 原始草稿、解析后的有效值、已保存值和运行中配置分离。主题继承值跟随有效草稿更新，非法输入保留；保存不改变运行中的终端。
4. 编辑器类型、布局、单位、分组和数值提示集中到 SettingsPresentation；核心仍负责最终配置解析。
5. 缓存搜索文本和主题目录；相同搜索结果复用控件。列表状态独立保存，千条列表新增时仅显示原有批次及新增行。主题目录新增或删除文件会使缓存失效。
6. 旧配置存储收缩为只读迁移，移除旧加载、恢复默认、快照写入及外部编辑桥接。独立快捷键录入组件，通过局部响应者协议接收按键，失去焦点取消。

## 验证中修复的问题

- 新增长列表测试发现 Advanced 编辑器在加入视图层级之前启用了宽度约束。修正为先加入再启用约束，重跑通过。
- 实际界面测试发现 Limited 模式尚未填写数值时，被自己的草稿刷新重置为 Auto。编辑器现在区分自己的输入与外部值更新，新增原生回归并重跑 UI 通过。
- 单个 Swift Testing 方法的无括号过滤未选中测试；该次零测试运行不计入验证，改用完整 SettingsTests 套件确认通过。

# 核心精简与原生异步修复（2026-09-23）

版本保持 0.2.3（build 13）；平台为 macOS 27 / Apple Silicon arm64，Zig 0.16.0。

## 本轮范围

1. CI 普通运行使用 `terminal.` 模块过滤，覆盖解析、页面、屏幕、搜索等终端核心测试；发行标签运行完整核心测试。
2. 删除不再被调用的 CRC32C、Struct／TaggedUnion／Packed 辅助文件，以及 Parser、Stream、Page 中无使用者的 C 表示与转换。使用 Zig 语法树定位声明后生成精确补丁，保留实际解析、存储布局和内部 GhosttyKit 桥接。
3. 尺寸提示的异步任务在取消后立即返回，避免旧任务写入新状态。
4. 快速终端关闭确认等待当前动画完成、窗口可见且取得焦点、终端视图已挂载；取消、隐藏及替换动画结束等待，旧动画回调不能完成新一轮展示。
5. 配置帮助移除不支持的平台说明及运行时重载承诺，改为当前 macOS 行为与重启生效说明。只修改帮助注释，不更改配置键、默认值或解析行为。
6. 终端实体初始化共用一条路径；快捷指令缩略图直接渲染最长边 256 像素的 sRGB PNG，保存编码结果，避免重复 SwiftUI 渲染与 TIFF 编码。
7. 核心构建、测试、原生构建及手动缓存清理共用项目锁。`scripts/build.py` 统一核心／测试入口，`macos/build.nu` 自动进入同一管理路径。锁覆盖整个构建过程，退出后由系统释放。

## 使用与边界

日常核心构建使用 `python3 scripts/build.py core`，核心测试使用 `python3 scripts/build.py test`，原生构建继续使用 `nu macos/build.nu`。原始 `zig build test` 不参与项目锁；活动进程检查只能提供保守保护。8 GiB 是构建前清理阈值，不是运行中磁盘硬配额。

本轮没有性能基准结论，也没有提交、安装或发布应用。测试与应用复用既有构建目录，结果包在提取摘要后清理。

本轮生成的 8 个测试结果包（含失败排查时的截图附件）、临时语法树工具与图片排查脚本均已删除；保留小型文本日志与 JSON 摘要。Zig 编译缓存约 3.1 GiB，仓库内应用构建目录约 701 MiB，临时原生测试构建目录约 763 MiB。

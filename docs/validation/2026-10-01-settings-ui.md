# 原生设置窗口与内部存储验证

日期：2026-10-01。平台：macOS 27、Apple Silicon arm64、Debug。

## 实现范围

- Settings 菜单、⌘, 和命令面板打开同一个独立深色设置窗口。
- 八个分类、中文及配置关键字搜索、单项默认、撤销、重新读取、保存和恢复默认。
- 固定使用嵌入 LXGW WenKai Mono、16 pt、字体平滑加厚开启、强度 255；不读取终端字体偏好。
- 移除左下角字体说明，隐藏设置页右侧滚动条，保留滚轮和触控板滚动。
- 默认窗口尺寸保持 157 列、43 行。
- 用户设置存入应用支持目录中的 `Settings/settings.json`。首次迁移复制旧文件和已解析的引用文件内容，并逐项比较迁移前后的设置。旧文件保留，迁移后不再参与日常加载。
- UI 与命令行共用核心设置解析逻辑。`+edit-config` 提示使用原生设置入口。
- 保存前检查类型、枚举、数值范围和完整配置；非法草稿不能保存。写入采用文件锁、版本冲突检查和原子替换，上一次成功输入保留用于恢复。
- 编辑中的草稿与运行中终端配置分离。保存后重启生效；本次不包含热重载。

设置测试覆盖：无旧文件时的内部默认值、引用文件迁移、非法输入不改写记录、重启生效、并发草稿冲突、列表替换、单项重置、损坏记录回退与修复、旧配置成功快照迁移、写入失败保留草稿、单例窗口和固定字体。

UI 回归另外确认：本次运行中的窗口与快捷键继续使用启动时配置，重启后应用新标题、快捷键及窗口外观；旧文件被修改后不会覆盖已迁入的设置；恢复默认设置仍有效。

实际窗口截图通过 XCTest 附件保存，包含 `settings-overview`、`settings-invalid` 和 `settings-saved`。人工检查确认深色布局、默认 157 × 43、隐藏滚动条及中文错误提示。

## 验证边界

- 本次编译并测试了 Debug 原生应用，没有进行发布打包、安装替换或推送。
- 精确终端网格尺寸检查需要 ReleaseLocal，本次未重复执行；本次没有更改终端网格计算。
- 损坏但仍可解析的内部记录可回退到上一份成功输入。整个 JSON 无法读取时，保留原数据并使用内置默认值，用户可显式恢复默认设置。

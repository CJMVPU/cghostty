# 2026-10-08 设置后台解析与草稿发布

本轮从 `1c038c5aa` 继续项目主链路优化，版本保持 0.5.7 / build 47。实现设置解析与 UI 发布的执行边界，以及异步编辑的草稿版本保护。所有改动仅提交本地 Git。

## 实现

- `b50c3ad42`：独立解析工作由后台任务持有，跨执行器仅返回可发送的值、诊断和记录。保存拆成准备与提交，后者仍在文件锁内检查持久化 revision。
- `0d5f31814`：设置窗口的加载、编辑防抖、字体预设、继承恢复、关闭前校验和保存接入后台路径。每次编辑、加载或保存更新 draft revision；过时结果不能覆盖新草稿。关闭校验等待期间合并重复请求。
- `9d3d26c59`：临时配置的创建、读取和释放集中于 `Ghostty.ConfigHandle.swift` 的 nonisolated 静态方法。设置功能层不直接访问 C ABI；既有检查规则未放宽。

`ConfigHandle` 实例及其持有的运行配置继续受 MainActor 隔离。后台临时配置不离开一次同步调用，不跨越 await；成功、失败和取消路径均按作用域释放。没有新增 unchecked Sendable 或共享可变解析对象。

改回已保存显示值时，后台先验证去掉覆盖后是否仍得到该值。主题等依赖改变了默认值时，显式覆盖保留；成功恢复继承后复用对应投影，避免再次解析同一最终输入。无效原始编辑仍保留，界面继续使用最后一次有效的解析值作为其余字段的显示基础。

应用启动、迁移、恢复运行配置，以及现有同步工具/测试入口继续使用同步路径。本轮没有把整个应用启动异步化，也没有改变设置保存后重启生效的产品语义。

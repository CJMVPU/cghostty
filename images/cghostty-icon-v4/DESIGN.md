# cghostty 暗银色圆角边框图标

使用内置 imagegen 编辑原有 v4 图标，保留白色小幽灵、终端 chevron 眨眼、薄荷色吐舌和内部深蓝背景。边框使用较暗的哑光银灰金属与细密拉丝纹理，内侧圆角加大；右上方柔光照射，右上高光宽而柔和，向左下逐渐变暗，避免各边重复亮斑。

银色金属延伸至源画布四边及四角，外侧圆角由 Icon Composer 原生遮罩生成；银框外不再保留蓝色背景。方形画稿是编译用素材，最终外观请查看 `app-icon-512.png`，不要将源画布的方角当作应用轮廓。

最终方形画稿为 `artwork.png`，与 `../cghostty.icon/Assets/TerminalGhost-v4.png` 一致，规范到 1024 像素。Icon Composer 底色同步为暗银灰色。三个 `app-icon-*.png` 是 Xcode 27 Icon Composer 导出的 macOS 实际图标；1024 像素导出也供 Dock 插件使用。验收检查导出图与应用编译后的 ICNS。

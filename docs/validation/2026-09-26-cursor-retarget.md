# 连续搜索重定向与刷新节奏（2026-09-26）

## 修复

旧算法按两个逻辑目标之间的距离分配动画时间，却从当前插值位置开始移动。
长跳尚未结束、下一匹配靠近上一目标时，剩余的大段距离会被压入 24ms。

复现：字符宽 19px，从 0 向 1000px 移动；33ms 后目标变为 1019px。
主体此时约在 72.7px，仍需移动 946.3px。旧实现分配 24ms，
下一次 120Hz 采样前进约 277.7px。

新时长取逻辑目标间距和主体剩余距离对应时长的较大值，仍不超过 200ms。
保留现有速度衔接、转向限幅和反向处理，普通单格输入仍为 24ms。
尾部窗口 40–60ms、形状恢复 100ms、几何过渡 100ms 和放大 12% 均未修改。
同一复现场景的新曲线下一帧约前进 36.4px；八方向回归要求小于 50px，
并检查位置、起始速度连续、无过冲和在 200ms 上限内到达。

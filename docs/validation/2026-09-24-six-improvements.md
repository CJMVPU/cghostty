# 六项重构与优化验证（2026-09-24）

基线提交：`d1d49a6f5`。版本保持 0.2.5（build 15）。验证环境：Apple M5 Pro、macOS 27.0（26A428）、Zig 0.16.0；原生应用使用 ReleaseLocal。

## 改动

1. 无障碍接口统一读取不可变快照：滚动历史文本、可见范围、选区范围在同一次终端锁内采集；范围使用该文本的 UTF-16 偏移。矩形选区可返回多个范围，宽字符及组合字符不会按终端格数误算。原生端按原有 500 ms 懒刷新策略一起缓存这些字段。采集编号标识一次快照，不表示终端内容版本。只记录可见和选中区间，没有为全部历史建立逐字节坐标表。
2. 拖拽直接写入 16 字节 UUID，移除通用 Transferable 到 NSPasteboardItem 的异步转同步适配器和信号量等待；现有 Transferable 导入保持可用。
3. 核心构建指纹排除包目录内的 `zig-pkg` 下载缓存。缓存文件创建、替换不再使核心归档失效；真实依赖清单和源码仍参与校验。
4. `Command.wait` 只保留实际使用的阻塞等待接口，删除未使用的非阻塞忙等分支，迁移全部调用者。
5. 正则匹配工作区由一次链接遍历持有和释放，匹配间复用；高亮和点击查找均使用这条路径。编译后的表达式仍可共享，可变工作区不跨线程共享。原有 100,000 步、1,000 深度、8 MiB 堆预算及 UTF-8 校验保留。
6. 每个终端至多缓存一张原有尺寸上限为 256 像素的 PNG。成功完成的渲染帧编号、视图尺寸、显示缩放组成缓存键；失败生成不会缓存。App Intents 按 ID 解析及只读取元数据时不生成图片，候选展示按需生成并复用。

## 回归结果

- 核心定向测试：122/122 通过，72/72 构建步骤成功。覆盖 Command、StringMap、链接渲染及无障碍。新增无障碍用例比较既有文本格式化结果，覆盖跨页历史、空行、软换行、中文、emoji、组合字符、反向矩形选区、宽字符首尾占位格和滚动后的可见范围。
- PCRE2 包测试：4/4 通过。包含工作区交错复用、无效 UTF-8/偏移、未匹配，以及预算耗尽后再次匹配的结果与预算恢复。
- 原生测试：41 个套件、328 项测试，327 通过、1 跳过、0 失败。跳过项为已有的 Benchmarks 示例。真实终端验证了跨桥接快照在重置和销毁后的有效性、UTF-16 选区、完成帧编号更新，以及元数据实体不生成图片。
- Python 构建维护测试：24/24 通过。
- macOS arm64 范围、C 配置桥接、版本一致性、本地化、Swift 6 并发配置、变更文件严格 SwiftLint、Zig 格式及差异检查通过。

原生结果包：`/private/tmp/cghostty-six-native3.xcresult`。本轮没有运行桌面 UI 自动化，也未进行 VoiceOver 连续朗读及人工拖拽验收；原生测试中的窗口、PTY、渲染及剪贴板载荷验证不能替代这些人工使用场景。

## 局部性能测量

### 正则匹配

使用相同已编译表达式、同一包含 100 条 URL 的文本，每轮遍历 1,000 次，共 100,000 次成功匹配。旧分配方式通过保留的 `Regex.search` 便捷接口复现，新方式每次遍历创建一个工作区。每轮校验匹配数量，匹配规则和预算一致。应用构建和测试结束后，ReleaseFast 的五轮结果如下，单位为毫秒：

| 轮次 | 每次匹配分配 | 每次遍历复用 |
| --- | ---: | ---: |
| 1 | 46.749 | 41.707 |
| 2 | 55.420 | 42.098 |
| 3 | 46.646 | 40.592 |
| 4 | 45.309 | 40.102 |
| 5 | 44.941 | 39.674 |
| 中位数 | 46.646 | 40.592 |

此负载下耗时中位数降低约 13%。工作区创建次数按遍历次数计算，不再随匹配数量增加。

### 缩略图

ReleaseLocal 原生测试使用同一个 1600×800 的 AppKit 视图生成 256×128 PNG，连续读取 100 次并比较图片数据。每次生成合计 22.136333 ms；包含首次生成的缓存路径合计 0.2525 ms。测试确认生成调用由 100 次降为 1 次，另有独立测试覆盖帧编号、尺寸、缩放变化及失败后重试。

上述数据只衡量特定本机负载下的匹配和 PNG 生成/复用开销，不代表完整终端帧率、所有 App Intents 查询或所有机器都有相同比例的提升。

## 复现

将项目固定的 Zig 0.16.0 和 Nushell 放入 PATH 后，在仓库根目录运行：

```sh
python3 scripts/build.py test -Dtest-filter=accessibility -Dtest-filter=Command -Dtest-filter=StringMap -Dtest-filter=renderer.link --summary all
nu macos/build.nu --configuration ReleaseLocal --action test
python3 -m unittest discover -s scripts/tests -v
```

在 `pkg/pcre2` 目录运行：

```sh
zig build test benchmark -Doptimize=ReleaseFast --summary all
```

改动没有提交、打标签或发布；测试应用位于临时构建目录，未替换已安装应用。

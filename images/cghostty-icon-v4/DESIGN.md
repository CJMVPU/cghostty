# cghostty 银色边框图标

0.1.2 使用内置 imagegen 编辑原有 v4 图标：保留白色小幽灵、终端 chevron 眨眼、薄荷色吐舌和深蓝背景，增加拉丝银色圆角边框。没有添加文字或其他角色。

最终方形画稿为 `artwork.png`，与 `../cghostty.icon/Assets/TerminalGhost-v4.png` 一致；规范到 Icon Composer 的 1024 像素画布，避免边框被裁切。三个 `app-icon-*.png` 是 Xcode 27 Icon Composer 导出的 macOS 实际图标；1024 像素导出也供 Dock 插件使用。

## 编辑提示词

Use case: precise-object-edit. Edit target: existing cghostty macOS icon artwork. Add a refined metallic silver frame around the navy icon tile, a continuous rounded-square border about 3 percent of canvas width, inset 9 percent from each edge, corner radius about 20 percent of canvas. Brushed polished silver, restrained light highlights and dark silver bevel, premium native macOS appearance. Preserve exactly the existing adorable white three-dimensional ghost, face, chevron wink, mint tongue, waving arm, tail, navy background and composition; do not redesign the mascot. Keep the silver frame behind and clear of the ghost, subtly scale the entire existing composition down only if necessary to fit within the frame. Full square navy canvas with no transparency and no rounded outer canvas corners, Icon Composer will mask it. No text, no extra objects. 1024x1024 PNG.

# 流解析续传跟踪移除（2026-09-23）

版本：0.2.3（build 13）。平台：macOS 27 / Apple Silicon arm64；Zig 0.16.0。

## 范围与方法

- 删除 `stream_continuation.zig` 的快照续传跟踪、输入保留与重放验证实现。
- 逐处删除 Stream 的跟踪字段、容量选项、初始化/释放、导出接口及三个输入入口的跟踪包装。直接使用原来的解析函数体。
- 删除基准工具的 `continuation-enabled` / `continuation-max-bytes` 参数及专用测试；常规 terminal-stream 基准保留。
- 使用 Zig 自带 `std.zig.Ast` 定位并生成精确补丁，删除 11 个专门验证已移除接口的测试；没有使用起止字符串截断源文件。被删除的独立模块还包含 8 个自身测试。
- 保留 4 个到达 ground 边界的测试，以及原有 UTF-8、OSC、APC、控制字符等分段解析测试。
- 将原快照恢复集成测试改为真实分段输入测试：对 63 字节混合输入的全部 64 个切分位置和逐字节输入进行验证，检查实际文本、光标、样式、标题，以及响铃、PTY 回复、通知、剪贴板动作各发生一次。
- 范围检查新增对已删除 snapshot 目录和续传模块的约束。

额外使用语法树提取改动前后 12 个解析函数体并比较 token 哈希。仅将 `nextUntracked` 到 `next` 的调用重命名归一化；12 个函数全部相同，包括 UTF-8、VT 状态、批量解析、边界处理和 APC/OSC 消费逻辑。

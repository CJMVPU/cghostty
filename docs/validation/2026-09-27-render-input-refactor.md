# 渲染缓存、输入状态与批量关闭整理（2026-09-27）

## 改动

- 前景上传按每个可用帧槽记录行版本、长度和位置；只复制变化或因前行
  长度改变而移动的行。首尾保留退化光标槽，闪烁不再移动全部文字。
  缓冲区增长或更新失败后强制完整重传，避免发布半更新状态。
- 滚动内容纹理按文字内容、图片和背景变化失效，不再因单独的光标
  变化重建。图片上传重试也会使缓存失效。`ScrollScene` 集中管理
  三个纹理、历史索引、运动状态及释放；绘制顺序和共享命中仍由 Renderer 管理。
- `LinkHitCache` 缓存一个逻辑行的有序正则匹配与未命中结果。
  内容、页面、视口、屏幕、修饰键和配置变化会失效；最多保留 1024 个
  匹配，超限回退直接查找。重复悬停同一链接单元格避免字符串与原生通知工作。
- `Keyboard` 接管键表栈和序列写入队列的所有权；实际输入编码、动作和
  IO 仍留在 Surface。结束序列时，即使队列已空，也按要求释放保留容量。
- 两种批量关闭标签页共用目标筛选、确认、关闭和撤销逻辑。确认使用原始
  目标快照，执行前排除已经离开标签组的窗口；重复撤销恢复原有顺序和会话。

此次保持现有光标效果。GPU 光标覆盖层仍使用原来的绘制范围；没有建立
同环境修改前后 GPU 对照，暂不扩大这一部分改动。Surface 拆分仅覆盖
键盘状态与链接命中，未重写全部输入分发。

## 工作量证据

确定性单测包含 3 个帧槽、60 个文字单元和 30 次光标显示切换。
原来每次完整上传文字的下界是 57,600 字节，本实现复制 896 字节，
减少约 98.4%。这是该单测的 CPU 到 GPU 缓冲区复制量，不能解释为
整机性能、GPU 耗时或功耗提升 98.4%。

链接缓存回归在同一逻辑行依次查询 7 个位置，包含命中和未命中，
只重建 1 次；同时检查重叠规则优先级、屏幕切换、超限和分配失败重试。

## 验证

- Zig 定向扩展回归：556/556 通过，72/72 构建步骤成功。
  过滤器为 renderer、input、surface、Session、terminal.accessibility
  和 terminal.render，包含此次新增模块测试。
- 重新构建核心并运行完整原生测试：349 项、45 个 suite 通过。
  批量关闭参数化测试覆盖两种关闭范围，各自连续两轮撤销与重做，
  校验标签顺序、原生注册表和原有核心会话。
- 桌面测试发现旧颜色缓存用例仍使用已禁用的用户 `palette` 配置，
  在到达画面断言前打开配置错误窗口。测试改为直接输出 RGB，保留原断言。
  滚动测试也改为通过隔离配置开启 trace，适配 Xcode 启动时不读取 CLI 配置的行为。
- 滚轮用例改用跨越字符行的距离；原来的小手势可能只改变光标截图。
  trace 不足一批时，直接终止空闲进程会丢掉尚未写盘的记录；单纯等待不能
  刷新这批记录。因此测试禁用撤销保留，正常关闭终端、释放会话并刷新日志后
  再断言。区域运动曾出现固定 16 张截图没有抓到
  过渡帧的失败，改为有 5 秒上限的条件采样，保留过渡帧和状态栏位置断言。
- 光标桌面回归 4 个用例均通过：Metal 主体/拖尾、关闭垂直同步的相同场景、
  宽字符与形状切换，以及修正配置后单独重跑的颜色缓存刷新与闪烁切换。
- 最终完整滚动桌面回归 3/3 通过：区域运动且状态栏固定、同步输出边界，
  以及历史滚动和实际 Neovim 鼠标滚动。前述失败及修正保留在本记录中。
- 版本、131 个原生文件的类型化桥接、510 条本地化、9 个 Swift 6 配置检查通过；
  全仓库 Swift 严格 lint、修改文件 Zig 格式与差异检查通过。
- 最终 scope 检查通过：仅支持 macOS 27+ arm64，其他目标与移除的构建选项均被拒绝。
- Python 脚本回归 38 项中 34 项通过、4 项按依赖条件跳过。

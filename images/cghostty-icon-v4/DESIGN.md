# cghostty 圆润小幽灵

按用户要求使用内置 imagegen 生成更立体、圆润、可爱且搞怪的版本：棉花糖般胖乎乎的身体，终端 chevron 眨眼表情，薄荷绿吐舌微笑，挥手姿态和小卷尾巴。保留白色、薄荷绿、深蓝身份配色。

应用使用 `../cghostty.icon`；`artwork.png` 是方形原画，`app-icon-1024.png` 与 `app-icon-64.png` 是 Xcode 27 Icon Composer 导出的实际 macOS 图标预览。v2/v3 目录仅保留此前设计稿。

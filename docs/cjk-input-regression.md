| 场景 | 结果 |
| --- | --- |
| Python `input()`，未导入 readline：单字“你”后退格 | 输入为空，画面中的字被擦除 |
| 同上：“你好”后连续退格两次 | 输入为空，画面残留“你”，复现系统回显宽度不足 |
| 修复后的输入框：首字删除、两个中文全部删除 | 输入为空，画面无残留 |

| “你好世界”左移两字后退格 | 输入和画面均为“你世界” |
| 90 个“中”跨行后连续退格 90 次 | 输入为空，原来两行中的字均被清除 |

## 系统回显与终端行为的边界

cghostty 已在 `src/pty.zig` 中启用 `IUTF8`。macOS 默认行编辑能删除完整 UTF-8 字符，
但其擦除回显仍可能只发送一次 `BS SPACE BS`。中文占两列：这组指令虽可清除末尾宽字符，
却只让光标净左移一列；重复后可能只擦除空格，留下前面的中文。

这不是 GPU 残影：终端文本读取也包含残留字，与收到的字节序列一致。
终端不能把所有 BS 都改成按中文字符跳两列，否则会使已正确计算显示宽度的行编辑器多退。
应用输入层的 readline 修复解决了本次聊天场景。

## 自动化回归

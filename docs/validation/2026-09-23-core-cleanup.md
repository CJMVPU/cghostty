# 内嵌字体与核心收敛（2026-09-23）

本轮实现及本机验证已完成。环境：Apple Silicon arm64，macOS 27.0（26A428），Zig 0.16.0，Xcode macOS 27 SDK。版本维持 0.2.2（build 12）；没有提交、发布或替换已安装应用。

随后按用户要求将源码版本提升为 0.2.3（build 13），同步发布说明和三个应用构建配置，并通过版本一致性、项目格式及差异检查。这一步只更新版本元数据，没有重新构建；下文构建与运行测试对应提升版本前的 0.2.2（build 12）产物。

- 文楷 Medium 重新嵌入可执行文件，CoreText 从内存加载；删除外置 TTF 安装和按 URL 加载路径，保留 OFL 许可。
- 删除七个无引用测试字体（12,128,012 字节），保留仍用于测试的 Noto Emoji 与其 OFL 声明；渲染错误集合收缩至 19 项。
- 删除 terminal/snapshot 及基准，搜索历史补入回归改用直接构造页面。应用继续保留滚动历史、压缩、窗口恢复与搜索。
- 删除独立终端 SDK 的 artifact/c_abi/Features 选项，原生终端枚举与数据结构去除动态 C ABI 包装；内部 GhosttyKit 桥接保留。
- Kitty 图片与 tmux 固定启用，删除空实现分支。应用构建的 build_config.artifact 仍区分内部静态桥接和辅助工具，不属于已移除的终端 SDK 选项。
- 主题刷新采用无载荷 apply_theme 动作；SIGUSR2 仍安全忽略并提示重启，不再调用空重载方法。
- AppleScript 五个命令共享主线程入口、权限检查及目标解析；CommandEntity 使用 ComputedProperty。
- 错误界面直接使用应用图标；扩展文件按 NSColor/NSPasteboard 合并；核查并保留快捷终端实际使用的三个私有 Dock 函数。

## 系统兼容边界

- titlebarView/NSTabBar 等私有视图查找仍用于原生标签布局与命中测试，保留 responds(to:) 与空值回退。
- _cornerRadius 仍用于玻璃背景圆角，已有 selector 检查和空值回退。
- CGS Space 查询仍用于全屏窗口所在空间判断；Dock 的三个私有函数通过封装用于快捷终端避让、隐藏和恢复，保留现有实现。
- 自动填充关闭设置涉及此前无法稳定复现的性能问题，不能以一次正常运行证明原问题消失；保留并记录此边界。
- 无所属窗口的标题输入框使用 runModal，这是必要的展示分支；macOS 27 的真实模态循环回归已验证按钮布局、可见性和默认按钮响应，旧 RC 注释已更新。
- 标签附件使用 NSStackView/NSButton，是现有原生实现而非待删除的死代码；不会仅为换用 SwiftUI 而重写。

核心测试使用 `zig build test -Demit-macos-app=false --summary all`；先构建核心，再通过 `nu macos/build.nu --configuration ReleaseLocal` 构建或测试原生应用。界面测试复用同一个测试产物目录，三组共 11 个测试通过。

新增的无所属窗口模态对话框测试在真实 `NSAlert.runModal` 循环中验证按钮布局、可见性、可用性及默认按钮点击返回值。字体界面截图已人工查看：中英文文楷及粗体、斜体、粗斜体显示正常。上述结果仅覆盖已执行场景，不代表自动填充旧性能问题已被证明消失，也不保证未来系统版本继续兼容私有 API。

最终可执行文件为 41,011,648 字节，内含 25,445,000 字节的固定版本文楷；产物检查从 Mach-O 中定位字体并验证 SHA-256。Resources 中没有重复的文楷 TTF。删除旧测试字体共 12,128,012 字节，删除重复错误页 PNG 共 3,325,268 字节；历史 Git 对象不会因此自动缩小。

本轮构建后 `.zig-cache` 约 1.9 GiB，`macos/build` 约 700 MiB，共用测试产物目录约 760 MiB；继续复用这些目录。结果包及截图在提取摘要后清理，仅保留小型文本日志和摘要；这里记录的结果不依赖临时文件长期存在。

额外删除流解析续传跟踪的尝试被自动审批拒绝：大段字符串替换会触及解析核心，且该额外操作的配套验证不足。未执行该删除，保留 `stream_continuation.zig` 及相关解析行为；不影响本轮已完成的 snapshot 编解码子系统移除。

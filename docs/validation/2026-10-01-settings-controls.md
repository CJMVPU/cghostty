# 英文设置界面与字体选择验证

日期：2026-10-01。平台：macOS 27、Apple Silicon arm64、Debug。

## 实现

- 设置窗口的分类、名称、说明、错误提示、按钮与恢复默认对话框统一使用英文。使用自然语言名称，不再逐行显示原始配置键；原始键仍可搜索。
- 移除逐项默认按钮及默认值摘要，保留全局 **Restore Defaults**。
- 不超过四个选项的布尔值或枚举使用同行单选按钮。只有核心默认值确实为空的字段才加入 **Auto**，例如允许终端程序控制的光标闪烁。较长的选项列表仍使用下拉框。
- 搜索框保持固定边框，聚焦时仅显示光标，不绘制高亮焦点边框。
- 字体家族使用原生可编辑下拉框，支持名称补全、内置字体和系统字体；保留现有自定义字体名称与后备字体顺序，可添加和移除后备字体。
- 主字体列表的第一项固定为 `default:LXGW WenKai Mono:medium:thickened`。打开列表时从顶部显示。选择预设时设置内置字体、自动字体样式（内置字体实际为 Medium）、加厚开启、强度 255，保留后备字体。
- 保留自动样式发现，避免之后换为其他字体或使用后备字体时强行要求其提供 Medium 样式。仅当字体、样式、加厚参数符合预设时显示预设名称。
- 设置 UI 自身仍固定使用内置 LXGW WenKai Mono、16 pt、加厚开启、强度 255；终端字体选项不会改变设置 UI 字体。
- 保存仍在重启后生效。

## 实现中发现并修复的问题

直接替换 NSComboBox 的内部 cell 会破坏原生选择通知的转发。此时列表项能改变显示文本，但设置模型没有收到更新，保存按钮仍不可用。最终实现保留 NSComboBox 的内部结构，通过控件绘制方法应用固定字体渲染，并以真实点击默认项、保存、重启回读覆盖此路径。

macOS 将分段选项暴露为辅助功能 RadioGroup/RadioButton，选中值为数值。UI 测试按实际辅助功能结构定位和验证。
